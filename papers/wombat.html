WOMBAT

A multilingual, open-access working-memory test battery for Python and online research.

Ockelmann, J. F., Ulken, J. L., Baur, S., & Giroud, N. R. · Ongoing project

Purpose

Working-memory research uses a range of task implementations, versions, and language materials. WOMBAT provides a common open implementation intended to support comparison and reproducibility.

Implementation

The project combines several working-memory tasks in an adaptable system for controlled laboratory studies and online data collection.

Components

  • Reusable tasks for working-memory assessment
  • Python-based research workflows
  • JavaScript integrations for online use
  • Multilingual materials and documentation

Status

The test battery is an ongoing research and development project. For current access, collaboration, or validation information, get in touch.
